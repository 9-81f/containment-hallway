# Contained Hallway — 2D Top-Down Action Prototype

A compact, high-tempo 2D top-down action micro-game built in **Godot 4** and **GDScript**, featuring custom pixel art animations created in **Aseprite**.

- **Play in Browser:** https://neg981f.itch.io/contained-hallway
- **Free Character Asset Pack:** https://neg981f.itch.io/free-base-humanoid-male-pixel-guy-animations-godot-project-file

## Gameplay & Technical Highlights
- **Top-Down Movement & Combat:** Responsive directional movement paired with hitbox/hurtbox collision detection and immediate visual feedback.
- **Tight Micro-Game Loop:** Compact & straight-forward combat encounter with a single weapon and single enemy type spread across a single hallway.
- **Custom Art & Animation Pipeline:** All character sprites, idle/movement cycles, and action frames drawn and exported from Aseprite.
- **Web-Ready Build:** Configured and exported for frictionless HTML5 browser play on Itch.io.

## Controls
- **Move:** `WASD` / `Arrow Keys`
- **Run:** Hold `Shift` + Move
- **Action / Attack:** `Space` / `Left Click` *(active once weapon is equipped)*
- **Interact:** `E`
- **Inventory:** `I`

## Tech Stack
- **Engine:** Godot 4.5 (GDScript)
- **Art & Animation:** Aseprite
